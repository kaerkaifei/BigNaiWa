# 合成大奶娃 · 大棋盘改版

基于 [yhsome 的《合成大奶娃》](https://yhsome.github.io/BigNaiWa/)([GitHub](https://github.com/yhsome/BigNaiWa))制作的本地改版,原作版权归原作者所有。

## 改动内容(只动区域范围,玩法逻辑未改)

- **棋盘宽度拉满**:棋盘铺满浏览器窗口里面板以外的全部宽度(原版 420,改版约 4~6 倍宽,随窗口自适应)
- **井深翻倍**:700 → 1400,水果保持原始大小,棋盘内滚动查看(投放后自动回到顶部)
- **棋盘大小可调**:面板新增「棋盘大小」按钮,宽 / 高 / 页面缩放实时加减;最小为原版 420 × 700,高度最大 3000,宽度最大为窗口拉满
- **自动释放**:新增开关,可在整个 X 轴上随机位置自动投放
- **速度可选**:2 秒 / 1 秒 / 0.6 秒 / 0.4 秒 / 0.001 秒连发
- **一次性提示**:首次进入会提醒「自动释放」和「棋盘大小」按钮的存在(记录在 localStorage,只出现一次)
- 手动玩法与原版一致:鼠标移动瞄准、点击投放;← → 微调,空格投放,R 重开

## 玩法说明

相同的水果撞在一起越合越大,顶到警戒线会判负;两只神奶娃相撞得 500 分并奖励一枚复活币。

> 注:「排行榜」提交的是原作的服务器,在本改版页面可能无法使用,不影响游戏本身。
